## 🚀 Quick Reference

### Common Tasks

- **Create page**: `[[Page Name]]` or Ctrl/Cmd+K
- **Block reference**: `((` then search
- **Add property**: `property-name::` value
- **Create task**: `/TODO` or `-` then checkbox
- **Search**: Ctrl/Cmd+P
- **Query**: `/query` or `{{query }}`
- **Template**: `/template` to insert

### Keyboard Shortcuts

- **Search**: Ctrl/Cmd+K
- **Command palette**: Ctrl/Cmd+Shift+P
- **Zoom in**: Ctrl/Cmd+Up
- **Zoom out**: Ctrl/Cmd+Down
- **New block**: Enter
- **Indent**: Tab
- **Outdent**: Shift+Tab
- **Move block**: Ctrl/Cmd+Shift+Up/Down

### Query Examples

**All TODOs:**

```clojure
{{query (task TODO)}}
```

**Last 7 days journal:**

```clojure
{{query (and (page-property journal true) (between -7d today))}}
```

**Pages with specific tag:**

```clojure
{{query (page-tags [[tag-name]])}}
```

### Property Examples

```markdown
status:: active
priority:: high
due:: [[2026-01-30]]
project:: [[Project Name]]
tags:: tag1, tag2, tag3
```
