# Changelog (2026-05-17 to 2026-07-06)

## Spotlight

- **Comments** — Threaded comments land across desktop and mobile: comment on any block, react from the selection bar, tag comment blocks, and keep comment threads out of published exports. ([0e87a83](https://github.com/logseq/logseq/commit/0e87a830a42f2449a21a09f585edc56b5c0553a0), [d696a67](https://github.com/logseq/logseq/commit/d696a675b4081ef6316ffc794788d90a5d44d013), [29854b9](https://github.com/logseq/logseq/commit/29854b970888a62854c575da9b264a5e8f726a29))
- **Semantic search** — On-device semantic search powered by zvec, with an embedding server that starts on demand, a Python preflight check, and an opt-in toggle so nothing runs unless you ask for it. ([fd1906a](https://github.com/logseq/logseq/commit/fd1906a0c84135f30c34ae84a20876cc46057dbe), [2be07b1](https://github.com/logseq/logseq/commit/2be07b193dd354a21efaf963086fd63a5f967497), [ac90b8d](https://github.com/logseq/logseq/commit/ac90b8d4dabd88e6c264cfa17eb8aba46bf3903b))
- **A rebuilt CLI** — `logseq` is rewritten in OCaml/Melange with a strict interface, real error codes, Unicode-safe output, Windows path handling, and an agent bridge that lets coding agents act on a graph from comment blocks. It now ships with the desktop release. ([0caa286](https://github.com/logseq/logseq/commit/0caa2868b24214e5f61824f186acc001569590b2), [507a39f](https://github.com/logseq/logseq/commit/507a39fff451fdf0eec4ad195e704d0fdba49fa8), [1126090](https://github.com/logseq/logseq/commit/11260900196b80a29a6dbe88999e83dec43df814))
