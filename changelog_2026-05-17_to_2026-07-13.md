# Changelog (2026-05-17 to 2026-07-13)

## Spotlight

- **Inline comments** — Logseq gains collaborative block comments: comment on any block, react from a selection bar, and tag comment threads. The foundation for real-time collaboration on shared graphs. ([0e87a83](https://github.com/logseq/logseq/commit/0e87a830a42f2449a21a09f585edc56b5c0553a0))
- **On-device semantic search** — A new zvec-powered vector search lets you find blocks by meaning, not just keywords, running entirely on your machine. ([fd1906a](https://github.com/logseq/logseq/commit/fd1906a0c84135f30c34ae84a20876cc46057dbe))
- **A rebuilt command-line interface** — The Logseq CLI was rewritten from scratch in OCaml/Melange for speed and reliability, and gained an "agent bridge" that runs coding agents directly from graph comment blocks, plus new db-sync REST and MCP APIs. ([0caa286](https://github.com/logseq/logseq/commit/0caa2868b24214e5f61824f186acc001569590b2), [507a39f](https://github.com/logseq/logseq/commit/507a39fff451fdf0eec4ad195e704d0fdba49fa8), [3d10d64](https://github.com/logseq/logseq/commit/3d10d64562524f568b40dab9376be92819ecc30b))
