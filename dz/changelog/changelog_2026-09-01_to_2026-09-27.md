# Changelog (2026-09-01 to 2026-09-27)

## Spotlight

- **Markdown input for the CLI** — `logseq upsert block` takes a Markdown outline, resolves refs and properties, and rolls back pages it created if anything fails. ([0dce570](https://github.com/logseq/logseq/commit/0dce57090bc9900b817bff6af3a2c4e95ef8fe51))
- **Undo, redo, and paste you can trust** — A sweep of fixes restores moved blocks, property values, and tags exactly, and stops paste from moving the originals. ([7aa16a9](https://github.com/logseq/logseq/commit/7aa16a9fb8a37fe2d7e6b071e35f5e5adf6baac0), [d18c0a7](https://github.com/logseq/logseq/commit/d18c0a74badee9d82ca092a28efd2ba0c3258d5d))
- **No more whole-graph scans** — Journals, child lookups, block deletion, and the Markdown mirror stop walking the entire graph, so big graphs stay responsive. ([28fb23c](https://github.com/logseq/logseq/commit/28fb23cab42515f8b6844e7541e28c9586b842e0))
- **Coordinated DB workers** — Lock ownership moves into SQLite and the desktop app stops outdated workers at startup, so the app and the CLI share graphs safely. ([6fcc57d](https://github.com/logseq/logseq/commit/6fcc57d1dbd7b6909ce4ee10fdb745f8043a538e), [1d449c9](https://github.com/logseq/logseq/commit/1d449c97b61764ffc7edd79d8a832e9910527fd6))
- **Coming next: an OCaml DB worker and CodeMirror 6** — Feature branches replace the ClojureScript DB worker with OCaml and move code blocks to CodeMirror 6. ([cb755fd](https://github.com/logseq/logseq/commit/cb755fd5232d25e7c23456a699687b149913edf4), [993549f](https://github.com/logseq/logseq/commit/993549f41a11a4a4fec09c92819cc32979108c41))
