**Logseq update: May 17 to October 4**

What landed on master (latest release is still 2.0.1; this reaches you through nightlies):

- Inline comments on any block
- On-device semantic search (needs the `sidecar` folder; fixed in packaging on Oct 3)
- A rebuilt OCaml CLI that ships with the desktop app
- Faster big graphs and faster file-graph import
- Undo, redo and paste that restore blocks, properties and tags exactly
- Sturdier sync and encryption

Newest: block refs are always `[[uuid]]`, `((uuid))` is plain text, and `/Node embed` replaces `{{embed}}`. Scheduled and Deadline on today's journal now uses your local days.

Coming next (drafts, can change): an OCaml DB worker, an OCaml desktop shell and web UI, CodeMirror 6, a reworked table view.
