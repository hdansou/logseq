# Changelog (2026-04-27 to 2026-05-16)

## Spotlight

This release ships Logseq's first round-trip between DB graphs and on-disk markdown, expands the CLI with native query support, rebuilds the graph view, and hardens sync across reconnects, encrypted graphs, and large payloads. The closing days added a polish pass on Graph View V2, a new `:asset` property type, and a handful of quality-of-life features.

- **Markdown Mirror** — read-only on-disk markdown projection of DB graphs that updates as you edit, with per-graph opt-in, path-collision handling, and rename-aware cleanup ([PR #12589](https://github.com/logseq/logseq/pull/12589), [PR #12594](https://github.com/logseq/logseq/pull/12594), [PR #12596](https://github.com/logseq/logseq/pull/12596), [PR #12607](https://github.com/logseq/logseq/pull/12607)). Two-way sync is in development on a feature branch.
- **CLI matures** — `qmd query` for multi-part queries, `asset download` for sync, a unified backup path shared with the desktop app, and a fully bundled CLI in desktop releases ([PR #12340](https://github.com/logseq/logseq/pull/12340), [PR #12548](https://github.com/logseq/logseq/pull/12548), [635d4b7a73](https://github.com/logseq/logseq/commit/635d4b7a73), [08a479f2c8](https://github.com/logseq/logseq/commit/08a479f2c8), [3f5b52cc07](https://github.com/logseq/logseq/commit/3f5b52cc07)).
- **Graph View V2** — rebuilt for faster rendering on large graphs, with a follow-up task zoom-in view and interaction polish ([PR #12604](https://github.com/logseq/logseq/pull/12604), [d12beff383](https://github.com/logseq/logseq/commit/d12beff383), [9318205c32](https://github.com/logseq/logseq/commit/9318205c32)).
- **Sync reliability** — caps oversized snapshot payloads, scopes RSA key pair caches per server URL, recovers stale websocket sessions, and clears a long list of checksum, reconnect, and asset upload edge cases ([PR #12586](https://github.com/logseq/logseq/pull/12586), [293309801f](https://github.com/logseq/logseq/commit/293309801f), [70042a46df](https://github.com/logseq/logseq/commit/70042a46df), [009d93dc92](https://github.com/logseq/logseq/commit/009d93dc92)).
- **Quality-of-life polish** — `$` autopair for inline math, AVIF/CR2 image support, "Always on Top" window option, marketplace plugin search across descriptions, plugin thumbnails, and a wide pass of editor, import, and graph view fixes ([PR #12618](https://github.com/logseq/logseq/pull/12618), [PR #11997](https://github.com/logseq/logseq/pull/11997), [be34b7904a](https://github.com/logseq/logseq/commit/be34b7904a), [PR #12470](https://github.com/logseq/logseq/pull/12470), [5726ecaa21](https://github.com/logseq/logseq/commit/5726ecaa21)).
- **`:asset` property type** — first-class asset property with inline thumbnail picker, so file/image references live in a typed property slot ([PR #12506](https://github.com/logseq/logseq/pull/12506)).
