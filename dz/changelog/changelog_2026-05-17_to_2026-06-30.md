# Changelog (2026-05-17 to 2026-06-30)

## Spotlight

- **Inline comments** — Comment on any block, edit thread titles, and tag comment blocks; the groundwork for collaboration on shared graphs. ([0e87a83](https://github.com/logseq/logseq/commit/0e87a830a42f2449a21a09f585edc56b5c0553a0), [29854b9](https://github.com/logseq/logseq/commit/29854b970888a62854c575da9b264a5e8f726a29))
- **On-device semantic search** — A zvec vector index finds blocks by meaning, entirely on your machine. ([fd1906a](https://github.com/logseq/logseq/commit/fd1906a0c84135f30c34ae84a20876cc46057dbe))
- **A rebuilt command-line interface** — The CLI is rewritten in OCaml/Melange and ships with the desktop release. ([0caa286](https://github.com/logseq/logseq/commit/0caa2868b24214e5f61824f186acc001569590b2), [fabf692](https://github.com/logseq/logseq/commit/fabf692ca32c145f8b7932b773009db8a267b9c9))
- **Agent bridge** — The CLI runs coding agents from graph comment blocks and reports status and reactions back into the graph. ([507a39f](https://github.com/logseq/logseq/commit/507a39fff451fdf0eec4ad195e704d0fdba49fa8), [b940287](https://github.com/logseq/logseq/commit/b94028780809f4412290e702a77d791f94f353f7))
- **A new UI foundation** — React rendering moves from Rum to HSX and components move to Base UI, with popups, menus, and toasts reworked on top. ([d185ea5](https://github.com/logseq/logseq/commit/d185ea58ee749c78b226b4f5aeed126e944b6397), [e95f1e2](https://github.com/logseq/logseq/commit/e95f1e2a7fcdd1c562853935947492ef3a50f4c9))
