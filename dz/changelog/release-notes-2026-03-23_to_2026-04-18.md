# What's new — April 18, 2026

This release is about three things: a CLI that's ready for real work, editing that doesn't fight you, and sync that handles the hard cases — encrypted graphs, large downloads, self-hosted servers — without getting stuck.

---

## The CLI is a real tool now

The `logseq` command-line interface has crossed a threshold. You can manage tasks (list, filter by status/priority, update), back up graphs, inspect nodes and assets, search your graph, and install CLI skills — all from the terminal.

Output got a lot more readable too: tables adapt to your terminal width, `show` uses breadcrumb-style paths so you always know where you are, and 3-level tab completion means you rarely have to type a full command. Piping works — you can upsert a block and pipe it into `show` in one line.

A large pile of CLI bugs were fixed alongside this: partial upserts that silently did nothing, page deletions that left orphaned state, built-in nodes that could be accidentally modified, datetime properties crashing `show`, tilde paths not being recognized, and `remove block --id` triggering false positives. The CLI should now behave consistently across every operation.

---

## Editing just works

Undo and redo had a handful of frustrating edge cases — undoing on a local graph did nothing, pasting blocks lost their structure, inserting a block above another block could end up in the wrong position, and deleting a page sometimes left undo in a broken state. All of those are fixed. When you undo or redo, your text selection is restored too, so you land back exactly where you were.

Beyond undo, a dense set of editing regressions are resolved: date properties can be edited again, recycled pages redirect correctly, template insertion works properly, page-to-tag conversions no longer misclassify child blocks as class tags, task status doesn't flicker, and block indentation aligns correctly.

Large pages also render faster — linked references load lazily, and the page itself renders in a safer deferred order, so big graphs feel snappier without breaking layout.

---

## Synced and encrypted graphs are more resilient

If you use sync, this release eliminates a class of issues where the app thought your local graph and the server were out of sync when they weren't. That mismatch caused trouble after undo/redo or when reconnecting. It's been substantially stabilized.

For encrypted (E2EE) graphs specifically: if the app ever couldn't open your graph due to a key problem or a failed download, recovery is now much more robust. The app handles missing keys, decrypt failures, and stale key material gracefully instead of getting stuck in a loop.

**Self-hosted sync** gets first-class support in this release — you can now configure a custom sync server URL, and the app respects your configured scheme (http vs https) consistently.

Large graphs download faster. Instead of waiting for the entire snapshot to arrive before anything happens, data now streams in progressively from a dedicated sync worker. Search indexing also shows a progress indicator during the initial index of a large graph, so you know what's happening instead of staring at a spinner.

---

## Faster on larger graphs

Editing operations (save, insert, delete) are leaner — unnecessary intermediate transactions are eliminated, and sibling navigation uses lower-level datom lookups instead of full queries. Writes to the storage layer are debounced and batched more intelligently, reducing write amplification on graphs with thousands of blocks.

Views and page rendering got faster too: `get-view-data` is cheaper, linked references are deferred, block fetches are batched more safely, and low-level scans do less work per call. Search indexing runs faster and now reports progress while a large graph is being processed.

---

## UI and plugin improvements

- An "Open asset" action is now available in the block context menu
- Plugin sidebar integration uses normalized user keys for more consistent behavior
- Page creation retries more gracefully when state updates race with the UI
- Drag-and-drop assets, desktop image copying, and batch page deletions work correctly
- Dark theme is preserved when installing non-theme plugins
- Macro rendering and inline class handling are fixed

---

## Under the hood

Sync internals were reorganized — download and import logic moved into dedicated modules, worker auth and E2EE password state were consolidated, and remaining cross-thread calls from the DB worker were removed to tighten worker boundaries.

Undo internals were reworked around semantic operations instead of legacy transaction-data reversal, which makes undo/redo more predictable and easier to extend.

The plugin library and toolchain got a refresh, and legacy transit read/write code paths were cleaned up.

Test coverage expanded significantly: CLI end-to-end tests now include timings, manifest lint, sync fixtures, offline Chrome scenarios, and plugin E2E coverage. Checksum diagnostics are available in development builds for investigating sync regression paths.
