# What's New with Logseq — 2026-10-04

A snapshot of what landed on master between May 17 and October 4, written for people who want to know what's in it for them, not a commit list. Everything here is on master. The latest published release is still 2.0.1; newer work reaches you through the nightly builds until the next release.

---

## 1. Comment on any block

You can now leave an inline comment on a block, edit the thread's title, and tag comment blocks. Right-click a block and choose **Add comment**.

**What's in it for you**

- Leave notes on a block without changing the block's text.
- It is the groundwork for collaboration on shared graphs.

## 2. Search by meaning, on your machine

Semantic search finds blocks that mean what you typed, even when the words differ. The index is built and queried on your own computer.

**Check this first:** semantic search needs the app's `sidecar` folder. The 2.0.1 build we examined shipped without it, so the setting could be on while search quietly stayed keyword-only. Packaging was fixed on October 3, so nightlies built after that date should include it. If searches never find paraphrases, look for `Contents/Resources/sidecar/embedding_server.py` inside the app bundle.

## 3. A rebuilt command-line interface

The CLI is rewritten in OCaml and ships with the desktop app. It can run coding agents from comment blocks, and the old ClojureScript CLI is gone. On master, `logseq upsert block` also accepts a Markdown outline, resolves references and properties, and rolls back pages it created if anything fails.

**What's in it for you**

- Script and automate against your graph from the terminal.
- Check `logseq upsert block --help` on your build: the Markdown input is newer than some installed CLIs.

## 4. Big graphs feel lighter

Pages, journals and views now read from the database worker a piece at a time and virtualize what is off screen. Visible journal days load first, and whole-graph scans are gone from journals, child lookups, deletion and the Markdown mirror.

**What's in it for you**

- Large graphs open, scroll and edit faster.

## 5. Faster file-graph import

Importing an old file graph now streams file contents, parses Markdown outline-first, rebuilds references once, and shows progress. Icons, PDF annotations, timestamps and favorites carry over.

## 6. Undo, redo and paste you can trust

A sweep of fixes makes undo restore moved blocks, property values and tags exactly, and paste no longer moves the originals. In the last days of September the sweep also reached deleted blocks and pages that contain references, and a full undo stack now keeps its newest entries.

## 7. Sturdier sync and encryption

Stress testing drove fixes for stale transactions, checksums, deletes and missing assets. A wrong end-to-end encryption password now fails cleanly, and encrypted assets go up to 200 MB. Sync servers gain semantic REST and MCP APIs, which are not open to users yet.

## 8. References that resolve everywhere

A reference to a block or page is now always `[[<uuid>]]`. Search results, breadcrumbs and references nested inside page names show titles instead of raw ids. A reference to something that no longer exists stays visible as a broken link.

**What's in it for you**

- Type `[[` and search: the list includes blocks as well as pages, and picking a block inserts its reference.
- `((uuid))` is plain text in DB graphs, and `{{embed}}` is deprecated. Use `/Node embed` to embed a block or page.

## 9. Smaller things worth knowing

- **Scheduled and Deadline on today's journal** now uses local midnight. West of UTC, the old UTC window ended in the evening before the last day, so tasks timed late on that day were cut off. Tasks at 23:00 on the sixth day, for example, are now included.
- **Settings recover from a broken `config.edn`.** If the file cannot be parsed, toggles keep working, and your next settings change rewrites it from the default. Edit the file first if you want to keep your own settings.
- **A missing global `config.edn`** is recreated, including before a shortcut change is saved.
- **New asset blocks** land on the `#assets` page instead of today's journal.
- **Inline images** now get a menu with **Copy image** and **Show file in folder** on the desktop app.

## Coming next

These are on feature branches with open pull requests, and most are drafts. They can change or be dropped before release.

- **An OCaml DB worker** replaces the ClojureScript one. It keeps the same protocol and SQLite layout, so existing graphs open unchanged.
- **A native OCaml desktop shell** ports the Electron main process and the db-worker daemon.
- **A web UI written in OCaml** is a draft rewrite of the main UI on the LUI runtime. As written it drops mobile, graph view, whiteboards and Zotero, so expect discussion before it lands.
- **CodeMirror 6 code blocks** upgrade the code editor with plugin language support.
- **A reworked table view** adds sticky controls, value chips and multi-column sort.
- **Import preview** scans a file-graph import first, reports ignored items and supports plain Markdown folders.
- **Personal access tokens for sync** let you authorize db-sync API access with graph-scoped tokens.

---

## TL;DR — what should you actually try?

- **Right-click a block** and try **Add comment**.
- **Type `[[`** and search for text that is in a block, not a page title.
- **Type `/Node embed`** and embed a block or page.
- **Open today's journal** and expand **Scheduled and Deadline** to see the local-day window.
- **If semantic search never finds paraphrases**, check the app bundle for the `sidecar` folder.
- **Run `logseq upsert block --help`** and see which input your CLI accepts.
