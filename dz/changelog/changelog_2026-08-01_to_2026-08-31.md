# Changelog (2026-08-01 to 2026-08-31)

## Spotlight

- **Faster file-graph import** — Importing a file graph parses Markdown outline-first, reads files ahead through a pipeline, rebuilds references once at the end, and shows progress as it goes. ([2aee0eb](https://github.com/logseq/logseq/commit/2aee0eba1a8c35c06fe50120626c0c21b2cde196), [9387fe3](https://github.com/logseq/logseq/commit/9387fe323a4879b3e007324f93a76d23fca78ef8))
- **Worker-backed rendering settles in** — Journals load on demand and the UI, breadcrumbs, and search results render steadily from the DB worker. ([64fdf7e](https://github.com/logseq/logseq/commit/64fdf7e234c90a9276d61a088c72821f45d6b846), [1b80267](https://github.com/logseq/logseq/commit/1b80267914b1fc7ff62df587472ffd10049253ab))
- **A leaner CLI** — The legacy ClojureScript CLI is gone, leaving the OCaml CLI, which now builds with OCaml 5.1.1. ([df2623e](https://github.com/logseq/logseq/commit/df2623ea94d5d18c166cbb7acd2e0ef5adef2404), [bc45731](https://github.com/logseq/logseq/commit/bc4573139d05255f70848d398215651543f0712a))
- **Video embeds with timestamps** — Video embeds improve and YouTube timestamps become part of the note-taking workflow. ([336588d](https://github.com/logseq/logseq/commit/336588df618558786ec58ad1ef627d1f5adb763b))
- **Sturdier end-to-end encryption** — Wrong E2EE passwords fail cleanly instead of retrying, and encrypted assets go up to 200 MB. ([abdc94b](https://github.com/logseq/logseq/commit/abdc94bfb47cd7db924cd8a45ff3d114e8278604), [16aba8e](https://github.com/logseq/logseq/commit/16aba8ecf9d4dcca7ad4404a584d49307bf29d15))
