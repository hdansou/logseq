# Changelog (2026-03-23 to 2026-04-12)

## Spotlight

This release centers on three areas that materially improve day-to-day work in Logseq: a much more capable CLI, a stabilization pass on editing and undo/redo behavior, and deeper hardening of DB sync and encrypted graph flows.

- **Logseq CLI Expands into a Full Maintenance Toolkit** - The CLI now covers task workflows, graph backup, node inspection, asset management, search, skill discovery, and sync debugging. It also receives a broad usability pass across completions, output formats, and help text, making terminal-based graph work more practical for both developers and power users.
- **Block Editing and Undo/Redo Become More Reliable** - This release fixes a dense set of editing regressions around local graphs, pasted content, page deletion, insert-above behavior, ordering conflicts, and property history. The result is more predictable editing, especially in edge cases that previously broke undo history or left graph state inconsistent.
- **DB Sync and E2EE Recovery Improve for Large and Encrypted Graphs** - Sync work moves further into dedicated worker flows, large downloads stream more efficiently, and encrypted graphs recover more cleanly from missing keys or decrypt failures. These changes reduce checksum drift, improve resilience, and strengthen remote graph recovery.
