# Spotlight: 2026-05-17 to 2026-10-04

What landed on master across four and a half months, and what is being built on feature branches next. Full details live in the monthly changelogs.

## Shipped

- **Inline comments** — Comment on any block, edit thread titles, and tag comment blocks; the groundwork for collaboration on shared graphs. _(May–June)_ ([0e87a83](https://github.com/logseq/logseq/commit/0e87a830a42f2449a21a09f585edc56b5c0553a0), [29854b9](https://github.com/logseq/logseq/commit/29854b970888a62854c575da9b264a5e8f726a29))
- **On-device semantic search** — A zvec vector index finds blocks by meaning, entirely on your machine. _(May–June)_ ([fd1906a](https://github.com/logseq/logseq/commit/fd1906a0c84135f30c34ae84a20876cc46057dbe))
- **A rebuilt command-line interface** — The CLI is rewritten in OCaml/Melange and ships with the desktop app. It runs coding agents from comment blocks, drops the legacy ClojureScript CLI, and accepts Markdown outlines for `upsert block`. _(June–September)_ ([0caa286](https://github.com/logseq/logseq/commit/0caa2868b24214e5f61824f186acc001569590b2), [507a39f](https://github.com/logseq/logseq/commit/507a39fff451fdf0eec4ad195e704d0fdba49fa8), [df2623e](https://github.com/logseq/logseq/commit/df2623ea94d5d18c166cbb7acd2e0ef5adef2404), [0dce570](https://github.com/logseq/logseq/commit/0dce57090bc9900b817bff6af3a2c4e95ef8fe51))
- **Worker-backed rendering** — Pages, journals, and views read from the DB worker incrementally and virtualize. Visible journal days load first, and whole-graph scans are gone from journals, child lookups, deletion, and the Markdown mirror. Large graphs open, scroll, and edit faster. _(July–September)_ ([fb1047d](https://github.com/logseq/logseq/commit/fb1047d1f8ee5b14892b87d74ad49d0483cdee2a), [c3205d4](https://github.com/logseq/logseq/commit/c3205d4534860f47d759c453bea52d169f09edc5), [28fb23c](https://github.com/logseq/logseq/commit/28fb23cab42515f8b6844e7541e28c9586b842e0))
- **Faster file-graph import** — Import streams file contents, parses Markdown outline-first, rebuilds references once, and shows progress. It carries over icons, PDF annotations, timestamps, and favorites. _(August–September)_ ([2aee0eb](https://github.com/logseq/logseq/commit/2aee0eba1a8c35c06fe50120626c0c21b2cde196), [c9968e2](https://github.com/logseq/logseq/commit/c9968e2297707aae45db34ea9a5f387b28d02708), [3302f9e](https://github.com/logseq/logseq/commit/3302f9eae5f12e8f84815d404f6a926da0909832))
- **Undo, redo, and paste you can trust** — Moved blocks, property values, and tags restore exactly, and paste no longer moves the originals. _(September)_ ([7aa16a9](https://github.com/logseq/logseq/commit/7aa16a9fb8a37fe2d7e6b071e35f5e5adf6baac0), [d18c0a7](https://github.com/logseq/logseq/commit/d18c0a74badee9d82ca092a28efd2ba0c3258d5d))
- **Sturdier sync and encryption** — Stress testing drove fixes for stale transactions, checksums, deletes, and missing assets. Wrong E2EE passwords fail cleanly, and encrypted assets go up to 200 MB. Sync servers gain semantic REST and MCP APIs. _(July–August)_ ([f983366](https://github.com/logseq/logseq/commit/f983366d5165589919243aa75efc3c85265cfc31), [abdc94b](https://github.com/logseq/logseq/commit/abdc94bfb47cd7db924cd8a45ff3d114e8278604), [3d10d64](https://github.com/logseq/logseq/commit/3d10d64562524f568b40dab9376be92819ecc30b))
- **Coordinated DB workers** — Lock ownership moves into SQLite and the desktop app stops outdated workers at startup, so the app and the CLI share graphs safely. _(September)_ ([6fcc57d](https://github.com/logseq/logseq/commit/6fcc57d1dbd7b6909ce4ee10fdb745f8043a538e), [1d449c9](https://github.com/logseq/logseq/commit/1d449c97b61764ffc7edd79d8a832e9910527fd6))
- **A new UI foundation** — React rendering moves from Rum to HSX, and components move to Base UI, with popups, menus, and toasts reworked on top. _(May–June)_ ([d185ea5](https://github.com/logseq/logseq/commit/d185ea58ee749c78b226b4f5aeed126e944b6397), [e95f1e2](https://github.com/logseq/logseq/commit/e95f1e2a7fcdd1c562853935947492ef3a50f4c9))
- **References that resolve everywhere** — `[[uuid]]` is the one node-reference form. Search results, breadcrumbs, and refs nested inside page names show titles, and a reference to a missing node stays visible as a broken link. Settings toggles also recover when `config.edn` cannot be parsed. _(October)_ ([PR #13580](https://github.com/logseq/logseq/pull/13580), [PR #13551](https://github.com/logseq/logseq/pull/13551), [PR #13566](https://github.com/logseq/logseq/pull/13566))
