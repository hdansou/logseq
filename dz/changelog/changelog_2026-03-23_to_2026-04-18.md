# Changelog (2026-03-23 to 2026-04-18)

## Spotlight

This release centers on three areas that materially improve day-to-day work in Logseq: a much more capable CLI, a stabilization pass on editing and undo/redo behavior, and deeper hardening of sync, encrypted graph recovery, and large-graph performance.

- **Logseq CLI Becomes Safer and More Practical for Real Work** - The CLI now covers task workflows, graph backup, node inspection, asset management, search, skill discovery, and sync debugging. This update extends that momentum with atomic upserts, breadcrumb-style output in `show`, deeper command completions, and more protections around built-in nodes and ambiguous updates, making terminal-based graph work more dependable for both developers and power users.
- **Block Editing, Templates, and Large Pages Feel More Stable** - This release fixes a dense set of editing regressions around local graphs, pasted content, page deletion, insert-above behavior, ordering conflicts, template insertion, and property history. It also improves rendering for large pages and linked references so large graphs feel faster without breaking page structure or undo history.
- **Sync, E2EE, and Search Continue to Harden for Bigger Graphs** - Sync work moves further into dedicated worker flows, large downloads stream more efficiently, self-hosted sync gets custom server URL support, and encrypted graphs recover more cleanly from missing keys or decrypt failures. Search indexing also gets faster feedback with progress reporting, reducing uncertainty while large graphs are being processed.
